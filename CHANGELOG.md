## v0.2.0 — 2026-11-19 (unreleased)

- Ingests the IMDb datasets `title.basics.tsv.gz` and `title.ratings.tsv.gz` into two Delta
  Lake tables of the bucket `ingestio-imdb-delta`, under the prefix `imdb`, replacing each table
  with the latest snapshot in one Delta commit (`FullLoad`). Spec:
  [ingest_imdb_datasets](specs/ingest_imdb_datasets.md); docs:
  [docs/ingest_imdb_datasets.md](docs/ingest_imdb_datasets.md).
- One configuration file per table, `src/config_title_basics.json` and
  `src/config_title_ratings.json`, with a `convert` member of the job's own for `title_basics`.
- Callbacks of the job's own: `RequireRows` (an empty batch is an error), `AddLineage`
  (`_run_id` and `_source_modified_at`) and `ConvertColumns` (`0`/`1` to boolean, lists to
  arrays).
- `scripts/download_imdb.py` downloads the files on the host, one directory per file.
- A container (`Dockerfile`, `.dockerignore`, `compose.yaml`) with Java 17, pyspark 4.2.0,
  Delta Lake 4.4.1 and the Cloud Storage connector, which mounts the data and the credential
  file read-only. Authentication is through Application Default Credentials only.
- Tests with local targets and IMDb-shaped files of their own; none reaches a real bucket.
